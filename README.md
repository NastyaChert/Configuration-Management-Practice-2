# Визуализатор графа зависимостей NuGet (Вариант №2)

## 1. Общее описание
CLI-инструмент для анализа и визуализации транзитивных зависимостей пакетов **.NET (NuGet)** без использования готовых менеджеров пакетов и сторонних библиотек. Построение графа выполняется алгоритмом рекурсивного поиска в глубину (**DFS**) с поддержкой обнаружения циклических зависимостей и ограничения максимальной глубины.

## 2. Описание функций и параметров запуска
- `-p`, `--package` — имя анализируемого пакета (обязательный параметр).
- `-r`, `--repo` — URL-адрес индекса репозитория NuGet v3 (`https://nuget.org`) или путь к файлу тестового репозитория.
- `-t`, `--test-mode` — включение режима работы с локальным файлом тестового репозитория.
- `-v`, `--version` — целевая версия пакета NuGet.
- `-a`, `--ascii` — вывод зависимостей в консоль в формате ASCII-дерева.
- `-d`, `--max-depth` — максимальная глубина анализа зависимостей (по умолчанию `3`).
- `-l`, `--load-order` — вывод порядка загрузки зависимостей (топологическая сортировка).

## 3. Команды для запуска проекта и тестов
Запуск через скрипт в Windows:
`run.bat -p A -r tests/sample_repo.txt -t -a -d 4`

Запуск через скрипт в Linux/macOS:
`./run.sh -p A -r tests/sample_repo.txt -t -a -d 4`

Запуск модульных тестов:
`python -m unittest discover -s tests`

## 4. Примеры использования и сравнение со штатными средствами
1. Тестовый репозиторий (порядок загрузки): `python -m src.main -p A -r tests/sample_repo.txt -t -l`
2. Пакет Newtonsoft.Json: `python -m src.main -p Newtonsoft.Json -v 13.0.3 -r https://nuget.org -a -d 2`
3. Пакет Serilog.Sinks.Console: `python -m src.main -p Serilog.Sinks.Console -v 5.0.1 -r https://nuget.org -a -d 3`
4. Пакет AutoMapper: `python -m src.main -p AutoMapper -v 13.0.1 -r https://nuget.org -a -d 3`

### Сравнение со штатными средствами
Отличия от `dotnet list package --include-transitive`: штатный NuGet фильтрует зависимости под конкретный Target Framework (TFM), разрешает конфликты версий по правилу минимально подходящей версии и загружает пакеты параллельно с кэшированием, тогда как утилита объединяет группы зависимостей из манифеста и выводит строгий обратный пост-порядок обхода DFS.
